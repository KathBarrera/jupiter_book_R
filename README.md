# Métodos Estadísticos — libro en R (bookdown)

Libro web construido con **R** y **bookdown** para el curso de Métodos Estadísticos de la carrera de Ciencia de Datos (Universidad del Norte).

> 🚧 **En construcción.** Por ahora el repositorio tiene la estructura base del libro (capítulos, referencias cruzadas, figuras, ecuaciones y citas), y sobre esa base se irán agregando los contenidos del curso.

## Estructura

```
jupiter_book_R/
└── docs/              # Libro compilado en HTML (listo para GitHub Pages)
    ├── index.html     # Portada y prefacio
    ├── *.html         # Capítulos
    ├── libs/          # Estilos y scripts de gitbook
    └── search_index.json
```

## Herramientas

- R + [bookdown](https://bookdown.org/)
- Formato gitbook (HTML)
- GitHub Pages para la publicación
